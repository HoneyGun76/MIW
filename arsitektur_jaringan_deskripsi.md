# Deskripsi Arsitektur Jaringan MIW

Arsitektur jaringan aplikasi MIW menggambarkan proses interaksi antara pengguna dan sistem melalui internet. Pengguna melakukan akses ke situs miw.co.id melalui jaringan internet dengan menggunakan protokol HTTPS yang berfungsi untuk menjamin keamanan komunikasi data. Platform Railway berperan sebagai penyedia layanan infrastruktur cloud yang secara otomatis mengatur web hosting, manajemen database, sertifikat SSL, dan penyimpanan berkas. Di dalam lingkungan Platform Railway, terdapat aplikasi PHP MIW yang berfungsi sebagai komponen utama sistem dan melakukan interaksi dengan database MySQL untuk menyimpan dan mengambil data. Arsitektur ini memperlihatkan bagaimana sistem MIW diimplementasikan dengan memanfaatkan kemampuan Platform as a Service (PaaS) dari Railway untuk mempermudah pengelolaan infrastruktur dan meningkatkan keamanan data melalui koneksi yang terenkripsi.
